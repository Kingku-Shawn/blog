# 宝塔面板部署指南

目标：把 shawn 离线博客（静态站点）与管理后台（Python 服务）部署到宝塔面板所在的 Linux 服务器。

适用：宝塔面板 8.x / 9.x，CentOS 7+/Ubuntu 20.04+/Debian 11+，服务器需能通过面板或 SSH 访问。

---

## 0. 需要上传的文件（准备阶段）

在本机 `D:\Code library\shawn` 目录下，把以下内容整体上传到服务器：

```
D:\Code library\shawn\
├── www.shawn.com\       ← 主站全部页面（58 篇文章、8 个应用、js 目录）
├── o.shawn.com\         ← CDN 静态资源（JS/CSS/图片/字体）
├── cdn.jsdelivr.net\    ← 旧版钢琴采样库
├── favicon.ico
└── admin\               ← 管理后台（server.py + web\ 前端界面）
    ├── server.py
    └── web\index.html
```

推荐做法：在本机把以上内容压缩成 `shawn.zip`（不含 `admin\data` 数据库，服务器首次启动会自动创建），用宝塔面板的「文件」→「上传」传到 `/var/www/shawn` 位置，再右键解压。解压后确认目录结构为：

```
/var/www/shawn/
├── www.shawn.com/
├── o.shawn.com/
├── cdn.jsdelivr.net/
├── favicon.ico
└── admin/
    ├── server.py
    └── web/index.html
```

如果解压后多出一层同名目录（如 `/var/www/shawn/shawn/www.shawn.com/`），把内层内容移动到 `/var/www/shawn/` 下即可。

## 1. 确认 Python 环境

打开宝塔面板的「终端」（或 SSH 登录服务器），执行：

```bash
python3 --version
```

- 输出为 3.8 及以上：直接继续第 2 步。
- 提示未找到或版本过低：在宝塔「软件商店」搜索安装 Python（选 3.9 或 3.10+），或使用系统包管理器安装：
  - Ubuntu/Debian：`apt update && apt install -y python3`
  - CentOS：`yum install -y python3`

记录 `python3` 的完整路径（后续 systemd 方案需要），用 `which python3` 查看。

## 2. 添加站点

宝塔面板 →「网站」→「添加站点」：

| 配置项 | 填写内容 |
|---|---|
| 域名 | 你的域名（如 `blog.example.com`），无域名可填服务器公网 IP |
| 根目录 | `/var/www/shawn`（保持默认或修改为你的上传路径） |
| PHP 版本 | 选「纯静态」 |
| 其他 | 默认即可 |

创建完成后，点击该站点 →「配置文件」，把文件 `nginx-shawn.conf` 的全部内容替换进去（记得把里面的 `server_name` 和路径换成你的实际值），保存并「重载配置」。

## 3. 放行端口

- 宝塔面板 →「安全」→ 确认 80 端口已放行（防火墙）。
- 若服务器是云服务器（阿里云/腾讯云等），到云控制台「安全组」确认入方向 80 端口已放行。
- 无域名只用 IP 访问时，还需要放行 80；若 IP 无法访问，可改用「IP + 其他端口」方式（如 8080），需同步修改站点监听端口和云安全组。

## 4. 启动管理后台（二选一）

### 方案 A：宝塔 Python 项目管理器（面板操作）

1. 宝塔「软件商店」搜索「Python 项目管理器」，安装。
2. 打开「Python 项目管理器」→「添加项目」：

| 配置项 | 填写内容 |
|---|---|
| 项目名称 | shawn-admin |
| 项目路径 | `/var/www/shawn/admin` |
| Python 版本 | 选择已安装的 3.8+ 版本 |
| 框架 | 无（或自定义） |
| 启动方式 | 命令行 / 自定义启动命令 |
| 启动命令 | `python server.py --host 127.0.0.1 --port 8124`（虚拟环境内用 `python`） |
| 端口 | 8124 |

3. 保存后点击「启动」。项目状态显示「运行中」即可。

### 方案 B：systemd（通用方案）

1. 把 `shawn-admin.service` 上传到服务器 `/etc/systemd/system/` 目录（可用宝塔文件管理，也可用终端 `nano` 直接创建）。
2. 编辑该文件，把 `ExecStart` 中的 `/usr/bin/python3` 换成第 1 步查到的实际路径。
3. 终端执行：

```bash
systemctl daemon-reload
systemctl enable --now shawn-admin
systemctl status shawn-admin
```

看到 `active (running)` 即启动成功。日志查看：`journalctl -u shawn-admin -f`。

| 地址 | 预期结果 |
|---|---|
| `http://你的域名/` | 博客首页正常显示，点文章、进钢琴等应用均可打开，无 404 |
| `http://你的域名/article/` | 文章列表页 |
| `http://你的域名/admin/` | 管理后台登录页 |
| `http://你的域名/piano/` | 钢琴应用，点击琴键有声音（采样从本地加载） |
| `http://你的域名/user/login` | 站点登录页（支持注册与登录，不再依赖 QQ 扫码） |

管理后台登录：

- 超级管理员 `root` / `123456`
- 管理员 `admin` / `123456`

站点注册与登录：

- 访问 `/user/login` 可自助注册普通用户账号，注册成功自动登录并跳回首页
- 注册/登录请求走 `/api/*`，由 Nginx 反代到管理后台（配置已包含），无需额外改动
- 新注册账号出现在后台「用户管理」中，角色固定为普通用户

登录后到「文章管理」点「从离线镜像导入」，可把 58 篇文章导入管理后台（导入源为 `www.shawn.com\article` 目录，即服务器上 `/var/www/shawn/www.shawn.com/article`）。

### 5.2 工具页主题与接口离线化（本轮新增）

- 8 个工具页面（钢琴、乐器总览、物理画线、调音器、节拍器、卡林巴、吉他和弦、关卡编辑器）已按 soulsoft/blog 白玻璃拟态风格重渲染，站点名统一为「清逸的博客」，域名统一为 `*.shawn.com`。部署时确认 `www.shawn.com/soulsoft-tools.css` 存在，且 8 个工具页 `index.html` 已注入主题链接与品牌脚本（部署包已包含，勿用旧包覆盖）。
- 原站动态接口 `/api-v1/*` 离线不可达，管理后台（`admin/server.py`）内置离线桩接口，覆盖用户信息、CSRF、物理画线关卡/排行榜/编辑器、文章详情/分类/列表、评论列表/发表等。部署时确认 Nginx 把 `/api/`、`/api-v1/`、`/huaxian/rank`、`/huaxian/style` 全部反代到 8124（宝塔配置模板已包含 `location /api-v1/` 与 `location /huaxian/` 规则，勿删）。

- 服务对含非法字符的请求路径直接返回 404，不产生 500。

- 导航项受管理后台「工具管理」开关控制（关闭的工具全站导航隐藏），与 5.2 的 `/api/tools` 桩接口联动。

### 5.5 页面装修系统（本轮新增）

- 管理后台新增「页面装修」入口（`admin/web/editor.html`），提供可视化布局编辑器：组件拖入、拖拽移动、缩放、删除、属性编辑，PC 桌面（1200px）与移动 H5（390px）双端独立布局。

- 部署确认：`admin/web/editor.html` 随包上传（部署包已包含）；升级时直接覆盖旧包，数据库会自动创建 layout 配置（无则返回默认布局）。

## 6. 必做安全调整

默认账号密码是公开的弱口令，公网部署后尽快修改：

1. 用 `root / 123456` 登录管理后台 →「个人设置」→ 修改密码。
2. 在「用户管理」中新建强密码账号，把 `admin` 的密码一并重置。
3. 条件允许时给站点配置 HTTPS（宝塔「网站」→「SSL」→ 申请免费 Let's Encrypt 证书），避免明文传输密码。
4. 管理后台反代只暴露在 `/admin/` 路径，若无需公网访问管理后台，可在 Nginx 配置中给 `location /admin/` 与 `location /api/` 增加 IP 白名单：
   `allow 你的IP; deny all;`

## 7. 常见问题

| 现象 | 排查 |
|---|---|
| 站点页面 404 | 检查 Nginx 配置是否替换完整、`root` 路径与实际上传路径是否一致，`nginx -t` 后重载 |
| 管理后台 502/504 | 确认 Python 进程在运行（方案 A 看项目状态，方案 B 看 `systemctl status`）；确认端口 8124 监听在 127.0.0.1 |
| 登录后按钮无响应 | 浏览器缓存旧前端，Ctrl+F5 强制刷新 |
| 导入文章为 0 篇 | 确认 `/var/www/shawn/www.shawn.com/article/` 下存在 `a_*.html` 文件 |
| 修改 Nginx 后不生效 | 宝塔「网站」→ 站点 →「重载配置」；或终端 `nginx -t && nginx -s reload` |

## 技术说明

- 管理后台为 Python 标准库实现（http.server + sqlite3），零第三方依赖，服务器无需 pip 安装任何包。
- 数据库文件 `admin/data/admin.db` 在首次启动时自动创建，含默认账号与默认分类；升级前先备份该文件。
- 离线站点的根绝对路径映射（Vue 重写导航）已由 Nginx `try_files` 规则实现，与本地 PowerShell 版行为一致。
- `/api/*` 由 Nginx 反代到管理后台 8124 端口，站点登录页的注册/登录即通过该通道完成，与本地 PowerShell 版转发行为一致。
