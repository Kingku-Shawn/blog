## 打开方式（两种）

### 方式一：一键启动（推荐，功能完整）

双击 **`启动离线站点.bat`**，自动启动本地服务并打开浏览器。
完整保留所有交互功能：钢琴弹奏发声、节拍器、调音器、卡林巴、吉他试听、物理画线、文章代码高亮等。
该方式使用 Windows 自带的 PowerShell 提供服务，无需安装 Node.js、Python 等任何软件。

### 方式二：直接双击 HTML（仅静态内容）

直接双击 `www.shawn.com\index.html` 或其他页面，可查看文章正文等静态内容。
浏览器出于安全策略会拦截本地文件的脚本加载（file:// 协议限制），交互功能可能不生效，这是所有本地网页的通病，非镜像缺失。

## 管理后台

双击 **`启动管理后台.bat`** 启动后台服务（需本机已安装 Python 3.8+），浏览器访问：

```
http://127.0.0.1:8124/admin/
```

**默认账号：**

| 账号 | 密码 | 角色 | 权限 |
|---|---|---|---|
| root | 123456 | 超级管理员 | 全部权限，含用户管理 |
| admin | 123456 | 管理员 | 文章、分类、评论管理 |

**功能：**
- 仪表盘：文章、用户、评论、分类统计
- 文章管理：新增、编辑、删除、置顶、发布/草稿，可一键从离线镜像 `www.shawn.com\article` 导入 58 篇文章；编辑时可勾选多个标签与分栏
- 标签管理：自定义标签（新增、改颜色、删除）。前台"分类即标签"，点击标签云即可筛选出携带该标签的文章
- 分栏管理：文章分栏（如"技术杂谈"），前台侧栏按分栏筛选文章，与标签筛选联动互斥
- 工具设置：控制前台导航与首页"在线工具"区各工具的展示与隐藏，关闭后导航链接与工具卡片一并消失
- 关于我编辑：富文本图文编辑入口，每次保存自动在内容最上方追加"更新于 时间"时间戳，并保留最近 20 个历史版本
- 分类管理：增删改
- 评论管理：审核、删除
- 用户管理（仅超级管理员）：新增管理员/普通用户、编辑角色、禁用、删除、重置密码
- 个人设置：修改昵称、邮箱、密码

**数据存储：** SQLite 数据库 `admin\data\admin.db`，首次启动自动创建，密码采用 PBKDF2 加盐哈希存储。
**安全加固：** 登录接口带失败限流（同一 IP 一小时内失败 10 次以上返回 429）；请求体上限 2MB；标签、分栏名称自动过滤 HTML 与脚本；关于我富文本走白名单清洗（剥离 script/iframe/on* 事件等）；登录、注册、文章、标签、分栏等接口均做了输入清洗与参数校验，防止 SQL 注入与 XSS。

## 站点注册与登录

离线站点的登录页（`/user/login`）已改造为本地账号体系，不再依赖 QQ 扫码：

- 任意访客可自助注册普通用户账号，注册成功自动登录并跳回首页
- 登录页支持"登录 / 注册"双 Tab 切换，登录状态保存在浏览器本地
- 注册接口经离线服务转发至管理后台，账号同时出现在后台"用户管理"中（角色固定为普通用户）
- 超级管理员可在后台将普通用户提升为管理员，或禁用、删除
- 使用前提：离线站点（`启动离线站点.bat`）与管理后台（`启动管理后台.bat`）同时运行

## 页面装修系统（可视化布局编辑器）

- 入口：管理后台 →「页面装修」→ 打开装修编辑器（`http://127.0.0.1:8124/admin/editor.html`），需 root/admin 登录
- 功能：
  - 组件库拖入画布新增组件，支持 9 种组件：主视觉、侧边栏、文章列表、工具网格、文本、图片、卡片、分隔线、空白
  - 画布内拖拽移动组件（X 百分比 + Y 像素）、右下角手柄缩放、Delete 删除、方向键微调、复制、层级调整
  - PC 桌面（1200px 画布）与移动 H5（390px 画布）双端独立布局，右上角切换编辑
  - 右侧属性面板实时编辑组件内容与样式（标题、正文、图片地址、链接、排序方式、显示数量、标签等）
- 保存：点击「保存并同步前台」，布局写入数据库并生成新版本号，前台首页刷新后立即按新布局渲染
- 重置：可一键恢复默认布局（即原始首页结构）
- 前台同步：首页加载时从 `/api/layout` 拉取配置；未装修时保持原生渲染（零影响），装修后由渲染引擎按配置渲染，PC/移动端自动选择对应布局；文章排序、分栏/标签筛选、分页等交互完整可用
- 安全：编辑器保存走管理员鉴权（X-Token）；组件内容经后端白名单过滤（富文本标签白名单、URL 防 javascript: 注入），前台渲染全部转义
