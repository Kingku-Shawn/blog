# 重力线条关卡编辑器 - 提示
  • 场景中至少需要包含一个球和一个球筐。
  • 一个球筐最多能装下两个球，注意球和球筐的搭配。
  • 红色的球进入红色的筐才算成功。不同颜色的球需要配合相应颜色的筐。
  • 场景中的矩形面积不能太大，因为面积大的矩形会因为太重而把它下方的物体压扁了。
  • 请留意物体上那些红色感叹号，存在感叹号意味着没办法保存。
